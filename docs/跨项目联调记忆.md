# 跨项目联调记忆

> 更新时间：2026-07-09

本文档用于保存 `cardshop-trade-engine` 与测试辅助前端之间的跨项目上下文。两个项目不在同一个 Git 仓库中，但在 dev/test 集成测试阶段需要作为同一套联调资产维护。

## 1. 项目关系

| 项目 | 路径 | 职责 |
| --- | --- | --- |
| 交易引擎后端 | `/Users/mac/Documents/codeSpace/cardshop-trade-engine` | Java 21、Spring Boot、Redis/RabbitMQ/MySQL/Nacos/XXL-Job 业务链路实现和集成测试记录。 |

测试辅助前端不是生产管理后台，也不是旧卡管的一部分。它是 `cardshop-trade-engine` dev/test 联调期间的工程工具。

## 2. test188 部署入口

测试辅助前端已部署到 test188，HTTP 访问入口为：

- `http://apitest.kalaiwang.com/testSuite/console/`

远端部署与代理约定：

1. 静态资源目录使用 release 软链：
   - 当前入口软链：`/data/www/testSuite/console`
   - release 根目录：`/data/www/testSuite/releases/`

3. 当前只使用 HTTP 入口，不依赖 `apitest.kalaiwang.com` HTTPS 证书。
4. 页面请求通过同域代理访问后端，避免浏览器跨域：
   - `/testSuite/trade-api/dev/` -> `http://127.0.0.1:10080/`
   - `/testSuite/trade-api/test/` -> `http://127.0.0.1:10080/`
5. 前端生产构建时的页面请求地址应使用 `/testSuite/trade-api/dev` 和 `/testSuite/trade-api/test`；补投人工 curl 仍默认保留 `http://127.0.0.1:10080`，并登录 test188 执行。

## 3. 共同边界

1. 集成测试只考虑 `dev` 和 `test` 环境，不用 `local` profile 证明 Redis/RabbitMQ/MySQL 一致性。
2. 测试辅助前端只提供 `dev/test` 环境选项，不提供 `local` 环境选项。
3. Redis pending 补投人工入口仍受后端安全边界保护：
   - active profile 必须是 `dev` 或 `test`。
   - `trade.engine.integration.manual-job-enabled=true` 必须临时打开并重启应用。
   - 请求必须来自 dev/test 测试机 loopback，例如登录 test188 后 curl `127.0.0.1:10080`。
4. 测试辅助前端可以直接发送 HTTP/Actuator/V1 API 请求；Redis/MySQL 证据首版通过手工粘贴聚合，不让浏览器持有 Redis/MySQL 密码。
5. 前端页面不得持久化 `app_secret`、JWT token、AES/SM4 key、RabbitMQ 密码、Redis 密码、MySQL 密码。当前 token 和密钥只允许保留在页面内存或表单中，刷新后丢失。
6. `.env` 中密码、JWT secret、API key 等同类密钥值必须继续使用单引号包裹。

## 4. 变更联动规则

后端发生以下变化时，需要同步检查测试辅助前端：

1. `/v1/cardapi/**` 路径、请求字段、响应字段、签名参数或 token 规则变化。
2. Actuator 或 Prometheus 指标名变化，尤其是 RabbitMQ connection/channel/publish/consume 指标。
3. Redis pending 补投入口路径、开关、参数、返回字段或安全限制变化。
4. `docs/集成测试方案.md` 中 PEND-001 到 PEND-006 用例步骤、状态或证据要求变化。
5. dev/test Nacos、RabbitMQ vhost、端口或 test188 部署路径变化。

前端发生以下变化时，需要同步检查后端文档：

1. 请求工作台新增或调整联调用例。
2. 观测聚合页新增证据项、SQL/Redis/RabbitMQ 命令模板或结论规则。
3. 执行记录导出的 Markdown 格式变化，可能影响 `docs/集成测试.md` 回填。
4. 环境配置默认值变化，例如 dev/test API base URL 或补投 curl base URL。

## 5. 当前前端能力

测试辅助前端首版包含：

1. 请求工作台：获取 Token、创建直充订单、查单、作废、Actuator 检查、Redis pending 补投。
2. curl 生成：敏感 header 脱敏展示；补投命令默认生成测试机 loopback `127.0.0.1:10080`。
3. 数据观测聚合：粘贴 Actuator/RabbitMQ/MySQL/Redis 输出后解析 health、RabbitMQ connection/channel、MySQL 四表、Redis pending/DB_PERSISTED 等证据。
4. 执行记录：维护 PEND-001 到 PEND-006 的全量状态和证据摘要；前端若只导出 PEND-001/PEND-002/PEND-003，回填后端 `docs/集成测试.md` 时必须手工补齐 PEND-004/PEND-005/PEND-006 的延期、阻塞或待执行记录。
5. 环境配置：只允许配置 `dev/test` 页面请求地址、curl 地址和内部补投 curl 地址。
