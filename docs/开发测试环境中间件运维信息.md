### D7B 真实 Broker 集成测试参考

`RabbitPersistRechargeOrderBrokerIntegrationTest` 默认跳过，需要显式打开真实 Broker 测试开关：

```bash
export TRADE_ENGINE_RABBITMQ_IT_ENABLED=true
export SPRING_RABBITMQ_HOST=47.100.11.188
export SPRING_RABBITMQ_PORT=5672
export SPRING_RABBITMQ_USERNAME=admin_cardshop
export SPRING_RABBITMQ_PASSWORD='<从运维密钥获取>'
export SPRING_RABBITMQ_VIRTUAL_HOST=cardshop-trade-dev

mvn -pl cardshop-trade-engine-infrastructure -am \
  -Dtest=RabbitPersistRechargeOrderBrokerIntegrationTest \
  -Dsurefire.failIfNoSpecifiedTests=false test
```

该测试使用独立的临时 exchange / queue / DLX / DLQ 名称，并在测试结束后清理，覆盖：

- Quorum 队列、DLX、DLQ 的真实 declare。
- manual ack / nack 行为。
- 毒消息 reject 后进入 DLQ。
- Consumer 连接关闭后，未 ack 消息在新 Consumer 上重放。

### 管理 API 操作模板

如需在新环境重新创建 vhost，可使用以下模板。执行前必须确认目标实例是开发 / 测试 RabbitMQ，且密码通过环境变量注入：

```bash
export RABBITMQ_MGMT_URL='http://47.100.11.188:15672'
export RABBITMQ_USERNAME='admin_cardshop'
export RABBITMQ_PASSWORD='<从运维密钥获取>'
export RABBITMQ_VHOST='cardshop-trade-dev'

curl -u "${RABBITMQ_USERNAME}:${RABBITMQ_PASSWORD}" \
  -X PUT "${RABBITMQ_MGMT_URL}/api/vhosts/${RABBITMQ_VHOST}"

curl -u "${RABBITMQ_USERNAME}:${RABBITMQ_PASSWORD}" \
  -H 'content-type: application/json' \
  -X PUT "${RABBITMQ_MGMT_URL}/api/permissions/${RABBITMQ_VHOST}/${RABBITMQ_USERNAME}" \
  --data '{"configure":".*","write":".*","read":".*"}'
```

## 安全要求

- 不在仓库记录 MySQL、Redis、RabbitMQ、Nacos 明文密码。
- 不在测试输出、应用日志、异常日志中打印中间件密码、连接串密码或访问 token。
- 不把开发 / 测试中间件配置复制到生产环境。
- 需要长期保存的密码应进入公司密钥管理、部署平台变量或 Nacos 加密配置。
